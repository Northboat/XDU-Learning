# 文件批量分级重命名工具 README

📁 文件批量分级重命名工具

一款基于 PyQt6 开发的图形化工具，支持递归遍历指定目录下所有文件，根据配置文件中的关键词规则进行分级重命名，并提供完整的日志记录和统计功能，界面简洁直观，操作门槛低

## ✨ 核心功能

- **灵活目录选择**：支持手动输入目录路径或可视化选择根目录，处理范围覆盖根目录及所有子目录
- **分级重命名规则**：通过配置文件定义分组（如"秘密"、"一般"）及对应关键词，自动为匹配文件添加分组前缀（格式：★分组名★原文件名）
- **增量更新支持**：已添加前缀的文件可根据最新配置自动更新前缀，避免重复添加
- **完整日志记录**：自动在根目录生成 work.log，记录处理时间、文件修改详情及统计数据
- **实时统计展示**：UI 实时显示总扫描文件数、已修改文件数、未修改文件数及具体路径
- **配置文件管理**：一键创建/打开配置文件，支持自定义分组和关键词
- **自定义图标**：窗口及 Windows 任务栏均显示自定义图标，提升辨识度

## 📋 快速开始

### 1. 环境要求（开发/运行）

- **运行环境**：Windows 10/11（64位），无需安装 Python
- **开发环境**：Python 3.8+，PyQt6，PyYAML

### 2. 目录说明

- `app`中为可执行文件
- `v1`为命令行程序（包含源码），其使用需要把`.exe`和配置文件`.yaml`同时放在需要处理的根目录下双击`exe`执行
- `v2`为现有版本（包含源码）

### 3. 运行方式（用户使用）

1. 下载压缩包并解压，`app`目录下得到 `renamer_gui.exe` 和 `config.yaml`（若未找到配置文件，运行程序后会自动创建）
2. 双击运行 `renamer_gui.exe`
3. 点击「📂 选择目录」按钮，选择需要处理的根目录
4. （可选）点击「⚙️ 修改配置文件」按钮，编辑分组和关键词规则
5. 点击「▶️ 开始处理」，等待处理完成（处理结果会在下方显示框展示）

### 4. 配置文件说明

配置文件为 `config.yaml`，与程序.exe同级，采用 YAML 格式，结构如下：

```yaml
# 分组名:
#   - 关键词1
#   - 关键词2
秘密:
  - 图纸
  - 实验计划
  - 核心数据
一般:
  - 日程表
  - 会议记录
公开:
  - 宣传稿
  - 说明书
```

说明

1. 分组名可自定义（如"机密""普通"）
2. 关键词支持模糊匹配，只要文件名包含关键词即会匹配对应分组
3. 若文件匹配多个关键词，以第一个匹配的分组为准

## 🔧 开发指南

### 1. 技术栈

| 技术/库     | 版本要求 | 作用           |
| :---------- | :------- | :------------- |
| Python      | 3.8+     | 开发语言       |
| PyQt6       | 6.0+     | 图形化界面开发 |
| PyYAML      | 6.0+     | 配置文件解析   |
| PyInstaller | 5.0+     | 程序打包为EXE  |

### 2. 依赖安装

```bash
# 安装依赖库
pip install pyqt6 pyyaml pyinstaller
# 升级依赖（若有版本兼容问题）
pip install --upgrade pyqt6 pyyaml pyinstaller
```

### 3. 关键实现步骤

1. **UI 设计与布局**采用 QVBoxLayout + QHBoxLayout 嵌套实现界面布局，确保响应式适配
2. 通过样式表（QSS）实现椭圆形组件、颜色搭配等现代化视觉效果
3. 封装输入区、按钮区、显示区三大模块，提升代码可维护性
4. **核心业务逻辑**递归目录遍历：使用 os.scandir 实现高效递归遍历，支持多层子目录
5. 前缀处理：通过正则表达式 `^★.*?★` 匹配并移除旧前缀，避免重复添加
6. 后台线程处理：继承 QThread 实现文件处理逻辑，避免 UI 卡顿
7. **日志与统计**日志记录：自定义 log 函数，同时输出到控制台和日志文件，包含时间戳
8. 统计功能：实时累计总文件数、修改数，记录未修改文件路径，处理完成后统一展示
9. **图标与打包优化**图标设置：通过 QIcon 设置窗口图标，调用 Windows API 关联任务栏图标
10. 程序打包：使用 PyInstaller 打包为单文件 EXE，通过 --add-data 嵌入图标资源

### 4. 打包命令

```bash
# 基础打包命令（替换 app_icon.ico 为你的图标路径）
--onefile --windowed --name "renamer_gui" --icon="app_icon.ico" --add-data "app_icon.ico;." renamer_gui.py

# 若 pyinstaller 未添加到环境变量，使用完整路径执行（示例路径）
& "c:\users\northboat\appdata\roaming\python\python310\scripts\pyinstaller.exe" --onefile --windowed --name "renamer_gui" --icon="app_icon.ico" --add-data "app_icon.ico;." renamer_gui.py
```

## ❌ 常见问题

### 1. 运行时问题

- **问题**：点击「选择目录」按钮样式异常（非椭圆形）        **解决**：确保按钮设置了固定尺寸（如 setFixedSize(180, 60)），且样式表中 border-radius 为高度的一半（30px），并添加 !important 提升样式优先级      
- **问题**：任务栏图标显示空白        **解决**：检查打包时是否添加 --icon 和 --add-data 参数，程序中是否调用 SetCurrentProcessExplicitAppUserModelID 接口设置应用ID      
- **问题**：配置文件无法打开        **解决**：确认 config.yaml 与程序.exe 同级，且当前用户有读写权限，若文件不存在可重新运行程序自动创建      

### 2. 打包问题

- **问题**：提示“无法将‘pyinstaller’项识别为 cmdlet”        **解决**：使用 pyinstaller 的完整路径执行命令，或通过 pip 重新安装并添加到环境变量      
- **问题**：打包后运行提示缺少 config.yaml        **解决**：将 config.yaml 复制到 EXE 所在目录，或运行程序让其自动创建默认配置
